# meishe-effect-kit-android-sdk-skill

> Modular beauty and visual-effect skills for Android camera and video apps.

## Overview

Meishe Effect Kit Android SDK Skill provides composable, AI-driven beauty and effect components for Android. Add skin smoothing, face reshaping, virtual makeup, filters, and AR stickers to camera, live streaming, or video editing workflows without rebuilding a visual-effects stack.

## Key Skills

- **Beauty** — skin smoothing and facial enhancement
- **Face Reshaping** — natural face adjustment
- **Virtual Makeup** — real-time makeup effects
- **Filters** — style presets and color looks
- **AR Stickers** — interactive visual overlays

## Why This Skill

- Modular integration—use only the effects you need
- Real-time, AI-driven visual processing
- Built for Android camera and video pipelines
- Faster launch for beauty-camera and social video features

## Typical Use Cases

Beauty camera · live streaming · short video · social apps · video conferencing · e-commerce visual experiences

## Getting Started

1. Choose the effect skills for your scenario.
2. Integrate the SDK into your camera/video pipeline.
3. Configure beauty, makeup, filters, or AR assets.
4. Validate performance on target devices.
